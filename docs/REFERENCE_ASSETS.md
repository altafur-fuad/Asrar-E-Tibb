# Reference Images Included in This Pack

All user-provided image files were copied into `docs/reference_images/` so the owner can attach or reference them while working in Antigravity. They are visual references, not production assets. Use them to inform information hierarchy, spacing, responsiveness, colors and content grouping. Do not clone the shown brand names, logos, copy, clinician identities, prices, product reviews or unverified medical claims.

## Production image/data rules
Prefer matching medicine photos already present in the project assets/dataset, after verifying mapping and license. A reference screenshot is not a source for medical product details. If a medicine has no matching image, use a local placeholder. Do not upload user reference photos as if they were real inventory/product images.
