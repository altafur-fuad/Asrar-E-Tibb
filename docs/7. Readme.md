# Asrar-e-Tibb — Documentation Entry Point

This file is for AI coding agents and contributors who want the short operational summary.

## Existing product (to be verified in source)
The public repository README describes a Flutter/Dart app integrated with Supabase. Product areas include a medicine directory, Farmacia catalog/cart/checkout, TibbNews posts/likes/comments/profiles/notifications, a moderation/admin area, and private medication reminders/notes.

## Local development quick start (Windows PowerShell)
```powershell
git clone https://github.com/altafur-fuad/Asrar-E-Tibb.git
cd Asrar-E-Tibb
flutter doctor
flutter pub get
flutter analyze
flutter test
flutter run
```

These commands assume Git and Flutter SDK are installed and that project environment/config requirements have been satisfied. Follow [`9. Setup.md`](9.%20Setup.md) for web, Rust and environment setup. A successful command must be observed—not inferred.

## Key security principle
Private data is private because both the database and every server endpoint enforce authorization. A hidden button or client-side role check is not security. A user's ID, role, verification state, order owner, price or payment status must never be trusted just because the client sent it.
